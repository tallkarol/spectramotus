Download and unzip on the Pi

Sign in here on the Pi and download the ZIP. Extract it to your home folder, then open a terminal inside Spectramotus-Pi5-Karol.

This is a player kit, not a bootable OS image. Keep Dave’s working Pi 3 card as a fallback. Power off before connecting the camera; use the correct Pi 5 ribbon cable. Set your screen orientation in desktop settings.

Install, check, and start

Keep the Pi online for this one-time setup. Run these commands from the extracted folder:

sh setup.sh
rpicam-hello --list-cameras
python3 launch.py --camera csi

The camera check should list the ribbon camera. Close other camera apps, then click Start camera in the player. Setup also saves hardware-report.json.

Try the current movements

First try the manual buttons. Then open Detection details → Start 10-gesture test: five waves and five thumbs-ups. After that, try switching gestures while a reaction is playing and let it return to idle.

Choose Download timing report after each run. The included TEST-DRIVE.md covers continuous interaction, false triggers, offline playback, and a 30-minute run.

If tracking is slow, stop the launcher and compare the lighter camera setting under the same lighting and distance:

python3 launch.py --camera csi --camera-profile light
Full-screen mode and startup

Once the windowed test works:

python3 launch.py --camera csi --kiosk

Press S or click Setup for controls. Alt+F4 closes the player; Ctrl+C stops the launcher. After a successful test, enable startup:

python3 launch.py --camera csi --install-autostart

Enable desktop auto-login in Pi settings. Reboot twice and test without Wi-Fi. The kit’s README explains changing or removing autostart.

Camera troubleshooting and USB webcams

If the ribbon camera is missing from rpicam-hello --list-cameras, check its cable and connection with the Pi powered off. Use system python3, not a virtual environment. If it is busy, close other camera apps and stop/start the camera in the player.

For a USB webcam, use python3 launch.py --camera usb and allow the normal browser camera permission.

What is included—and what stays private

The kit works offline after setup. Camera frames stay on the Pi; the reports contain timing and tracking statistics, not camera images. No API key, account session, or generation credits are included or needed.

This download contains Karol’s media and is available only to the owner and admins. Each kit includes file checksums and release metadata. Unzip updates into a new folder and keep the previous kit until the new one passes testing.
